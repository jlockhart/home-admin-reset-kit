# Home Admin Reset Kit

A simple, self-serve household paperwork filing kit: folder templates, filename rules, a document index CSV, missing-documents tracker, renewal tracker, annual checklist, and short category guides.

Public trial page: https://jlockhart.github.io/home-admin-reset-kit/

Trial download: https://jlockhart.github.io/home-admin-reset-kit/downloads/home-admin-reset-kit-v0-trial.zip

Home paperwork checklist: https://jlockhart.github.io/home-admin-reset-kit/home-paperwork-checklist.html

## What it is

- A plain folder structure for home admin documents.
- CSV trackers for document index, missing documents, and renewals.
- Short guides for file naming, category choices, and yearly reset habits.
- Designed for Drive, Dropbox, OneDrive, iCloud, Finder, a NAS, or similar storage.

## What it is not

- Not tax, legal, financial, accounting, or compliance advice.
- Not a document-handling service.
- Not an AI agent product.
- Do not send private documents or sensitive details in feedback.
